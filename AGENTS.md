# Jiahao (嘉豪)

A dual-profile prompt-as-mental-model distribution: a generator profile
(advisory surface-signal rules) installed in the primary agent, and a
verifier profile (iron laws + six-rung ladder, blocking) installed in a
second-party audit agent.

## How to run

```bash
npm install
npm test                        # jest suite; JIAHAO_TEST_TIER=public for the public tier
node scripts/install.js --help  # install the skill into a host
```

## Stack

Node.js, jest. No build step; product QA lives in plain `scripts/`.
Adapters are generated by `node scripts/build-adapters.js`.

## Layout

- `src/` — SKILL.md single source of truth + runtime modules
- `hooks/` — hook scripts, hooks.json, runtime
- `adapters/` — generated per-host adapter bundles
- `scripts/` — install + product QA scripts (capability registry: `docs/gates.json`)
- `bench/` — evaluation corpora and research harnesses
- `test/` — jest suites
- `docs/adr/` — architecture decision records
- `.scratch/` — local-only work area, never committed
