## 2. 计数事实源：test-manifest + 生成区（D-002）

Fact source: `docs/test-manifest.json` — committed derived artifact
(lockfile pattern: committed, hand-edit forbidden, regenerate + CI
diff-check).

- `[mechanical]` Generator `scripts/build-test-manifest.js`:
  `enumeration.suites` + `enumeration.suite_files[]` derive from jest
  `--listTests` output (jest's own discovery — matches collection intent,
  independent channel vs JUnit); `junit.tests`/`junit.skipped` derive from
  the generator's blessed jest run via the same jest-junit-lite reporter;
  `--junit <path>` accepted to consume an existing artifact. `--check`
  mode = regenerate + diff (D-008 weak self-consistency).
- `[mechanical]` Manifest fields: `schema_version`, `_doc`,
  `generated_at`, `enumeration`, `junit`, `published_tip` pointer.
  JUnit-derived `suites` is a forbidden field — circularity red line.
- README declaration surfaces become marker-sentinel generated regions
  (ADR-0043 D-B spliceRegion precedent — fail-closed on missing /
  inverted / duplicate sentinels): the two English declaration sentences
  in `README.md` and the two zh-CN mirror sentences in
  `README-zh-CN.md`, regenerated by the same script, same commit
  (ADR-0079).
- `run-test-gate.js` drops `--expected-suites` argv entirely; canonical
  manifest path hardcoded. The gate no longer reads README — the
  declaration check is the static leg's job. Post-jest it asserts
  `collected == manifest` (suites AND tests) — catches battery-grown-
  without-regen drift. `ci.yml` call line degrades to bare
  `node scripts/run-test-gate.js`; same commit as the gate rewrite
  (ADR-0057 D-C registration migrates: the registered expectation now
  lives in the committed manifest).
- New gate leg `check-test-manifest` (separate `check-*.js`, registered
  in gates.json): (a) freshness — recompute enumeration at gate time
  (jest `--listTests`) vs manifest; (b) README sentinel blocks ==
  manifest-derived text in BOTH READMEs; leg output never implies
  battery status (name discipline). Runs regardless of jest state —
  kills the fail-fast masking class (E-25 window).
- Wiring re-anchors in the same round (D-002(vi)): `adr-0057-wiring` and
  `adr-0058-wiring` argv-shape asserts → call-line shape + manifest
  presence; `adr-0080/0081/0082-wiring` literal `--expected-suites 90`
  pins → re-anchored to the new form; `adr-0083-wiring:194`
  `argv == glob` pin → retargeted to `manifest.enumeration.suites ==
  glob(test/*.test.js)` (the argv independence guard was already
  file-enumeration reconciliation — re-anchor, not new mechanism);
  gates.json test-entry params block synced (ADR-0036 D4
  check-gate-params).
- Pack budget: manifest must NOT enter `package.json` `files`
  (ADR-0039 D3 headroom precedent; ADR-0079 D5 exemption pattern) —
  wiring asserts the absence.
- Authority: cite ADR-0043 Cluster-1 as the authorizing pattern —
  manifest authority = registration + generator + freshness check; no
  new authority class minted.
- `[mechanical]` Blessed-enumeration tier-invariance: verify the
  generator's enumeration equals the CI environment's once, and pin the
  generator invocation tier (env skew reds immediately via the freshness
  leg).

## 3. 拒绝处置契约：ADR-0090（D-003）

New ADR-0090 "countersign rejection disposition contract" (ADR-0084 is
itself queued — self-referential amendment forbidden; 0089
scoped-succession precedent: new ADR + scoped pointers).

Content:

- Generic rejection triple-clause: (a) NON-RETROACTIVITY — rejection does
  not retro-convict commits landed while the ADR was effective (ADR-0086
  rule-6 mirror); (b) DISPOSITION MENU = default floor — each registered
  disposition executes unless the owner names a different branch at
  adjudication; a non-menu branch requires an errata note recording the
  deviation (on-site invention becomes a registered deviation, not silent
  improvisation — menu binds legibility, not owner choice); (c) STATUS
  TRANSITION — rejected → status amend "Rejected at 2026-12-15 tide" +
  queue removal.
- Class rule (derived, not arbitrary): per-ADR concretization is
  mandatory only where the queued ADR introduced enforceable machinery.
  This round concretizes the four new-form members 0086–0089 (widening
  from D-001's named 0086/0089 — registered); label-only members
  (old-form ten + E-13 bare-form nine) take the supersession default by
  class.
- 0089's named disposition: classifier reverts to three-class enum,
  leg-225 degrades to advisory, `orphan-cites.json` preserved as
  historical registry (append-only, never deleted).
- 0090 self-row explicit: if 0090 itself is rejected at the tide, the
  queue reverts to the pre-0090 state knowingly — restoring the exact
  defect the critique flagged, registered as informed rejection.
- `countersign-overdue` leg (R2 machinery → ADR-0076 D-B carve-out:
  registered + counted + trend-row): three-stage ladder (ADR-0089 D-E
  precedent) — inside grace (return-by .. return-by+30d) the leg is
  SUGGEST/advisory; past grace it FAILS with declared-drift-shaped red

  asserts "no unadjudicated queue member may be silently permanent" —
  not "the owner must have acted by date X". Grace=30d registers the

  call; the owner-incapacitated residual is named honestly in the ADR.

- Tide-eve disposition re-verification step enters the closeout order —

- ADR-0090 prose carries no count lines (t33-D-002(vii)); queue

## 4. 审计面执行：checklist + coverage 块（D-004）

- Generator `scripts/build-audit-checklist.js` →
  `docs/governance/audit-checklist.json`: extracts every ci.yml job's
  ordered run lines (zero-dep parsing per check-ci-jobs `parseJobs` /
  check-ci-wiring `runLines` — the CI command surface); `--check` mode
  asserts committed == regenerated.
- Audit report contract new face: the Hard-acceptance table is followed
  by a machine-readable coverage block — sentinel `<!-- audit-coverage
  v1 -->` + fenced JSON array naming the commands the auditor actually
  re-ran. The generator's `emit` prints the checklist for the auditor to
  paste and attest — the auditor attests what they ran; the generator
  never co-signs.
- New gate leg `audit-surface`: asserts the latest audit report's
  coverage block ⊇ current checklist; missing block or missing items =
  FAIL. Temporal scope (commit-date effectiveness mirror): only reports
  authored on/after this convention's registration date are asserted —
  t33's committed reports are not retro-convicted; t34's own audit is
  the first block-carrying report (bootstrap).
- Interim clause retirement: when the checklist lands, AGENTS.md
  "Audit self-consistency (interim, grill-t33 D-004(i))" clause retires
  in the same round — replaced by a pointer to the mechanism; no
  coexistence window.
- defer-0076 `unfreeze_if` is mechanically satisfied when the checklist
  artifact + declaration land — the row flips `pending-evaluation` →
  `actioned` with a check-in note (registered mechanical act, not
  adjudication).
- `[mechanical]` Both new legs are R2 machinery → ADR-0076 D-B
  carve-out (registered, counted, trend-row'd); their suites enter the
  manifest-derived count.
- Constraint: the coverage leg asserts declared re-run coverage — it
  never co-signs result truth; verdict authority stays with the audit
  protocol. No prose-grep assertions — the asserted object is the
  contract block, never text format.
