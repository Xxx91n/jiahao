## Lessons learned

1. `captured-at-head` headers turn evidence files into doc citations: a
   rewrite-map regen MUST trail the evidence commit, which is why ADR-0083
   D-A defines the non-anchoring commit class - without it the ordering
   invariant cannot converge.
2. The never-commit registry's first fidelity test caught two drifts in
   its own seed: a `private/` rule claiming a path class that legitimately
   tracks a fixture, and five historical violations grandfathered as a
   closed LEGACY enumeration instead of being silently absorbed.
3. GitButler index desync persists: `git reset -q HEAD` before any
   porcelain-based leg; `but commit` rides explicit path-id allowlists;
   `git show --name-only` verifies the boundary after every commit.
4. The ci.yml parity pin moved from a literal-per-round to the glob-equal
   + lower-bound + known-file-hit form in the new wiring suite - the
   equal-wrong-values failure mode is now guarded structurally.
