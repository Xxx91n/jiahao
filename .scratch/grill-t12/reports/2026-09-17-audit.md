## 四、发现（缺失/弱化/跑偏 单列）

### F-A [硬缺陷 / Standards+Spec 双轴同中] README Architecture 计数陈旧 → CI 测试门在 tip 为红
- 证据：README.md:307 `- \`test/\` — 68 test suites, 1088 tests`（t11 残留，源自 51ee74c）与同文件 L214 `1112 tests across 69 suites` 自相矛盾；`node scripts/run-test-gate.js --expected-suites 69`（ci.yml:97 的 CI 测试门原命令）实测 **exit 1**：`FAIL: README (Architecture) declares 1088 tests / 68 suites, actual 1112 tests / 69 suites`。
- 性质：txr 的 stale-count 修复在同文件内改一处漏一处——正是 ADR-0056/0057 设此机检要拦的漂移类（"update the README in the same change"）。报告的验证表不含 run-test-gate（该门是 CI job 包装器，不在 gate:all 33 项内），故逃逸。
- 处置（打回修复窗口，审计不动手）：README:307 → `69 test suites, 1112 tests`。
- 修复后重跑清单：`node scripts/run-test-gate.js --expected-suites 69`（必须含，本次逃逸点）+ `npx jest --silent` + `npm run gate:all`。
