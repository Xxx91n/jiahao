## D-002 — 五语义专属防御机理与硬性判据专精化

- **原问题**: Q2 — 五语义专属防御机理与硬性判据专精化
- **我的原回答原文**: "同意"
- **规范化需求**:
  正式确立五种嘉豪行为的专属病理机理与不可绕过的法定判据，彻底解决 r4 粗暴扁平化导致的防御机理模糊问题：
  1. **语义①（自以为是完成 / 虚假完工）**：
     - 病理：将“局部动作执行完毕”偷换为“最终用户目标达成”。
     - 判据：**目标逐项物理核销（Goal vs Outcome Receipt）**。必须对照原始诉求逐条核验最终物理状态与可复现结果，未出示核销闭环凭证前，严禁输出任何“完成/搞定/已修复”声明。
  2. **语义②（自我安慰跑通 / 借口自洽）**：
     - 病理：遭遇红灯、报错、测试挂死时，编造“不影响主流程/既有问题/环境差异”自我脱罪。
     - 判据：**零借口红灯即死（Zero-rationalization）**。任何 exit≠0、单测失败或异常报错，唯一合规动作是承认失败并呈报原始物理证据，严禁任何非物理佐证的自圆其说。
  3. **语义③（颅内高潮 / 思维链幻觉）**：
     - 病理：在思考过程（CoT）中自我推导逻辑闭环，过度自信，把未经现实检验的推论当成既成事实。
     - 判据：**思维链置信度恒为零（Hypothesis until probed）**。思维链所有推导仅为待检验假设；未通过外部工具真实探针（日志/断点/状态/实跑）拿到物理事实回传前，严禁在外部表达确定性结论。
  4. **语义④（显摆不做事 / 文本挤占工具）**：
     - 病理：通过洋洋洒洒的小作文、宏大叙事展现“专业”，实际极少调用工具，用言语繁复掩盖实际动作匮乏。
     - 判据：**工具调用绝对前置与输出物理限长（Tool-first & Action throughput）**。有动作空间时工具执行永远先于文字；未获新物理数据前禁止长篇发表看法；外部交付回复硬锁最多 3 行结构化事实。
  5. **语义⑤（自造词句装高大上 / 虚饰黑话）**：
     - 病理：自造复合词、学术名词与长链多重定语句式，用词汇复杂度伪装认知深度。
     - 判据：**初中生通晓的大白话（Plain language filter）**。严禁自造任何在通行初中语文或标准工业技术外的名词；一个概念只用唯一通行普通词；解释长于结论直接删除。
- **显式约束/负向需求**:
  ① 严禁在后续心智模型融合中把这五套专精判据再次退化为含糊的口号；
  ② 专精机理本身必须严格遵守大白话准则，严禁以黑话反黑话；
  ③ 任何偏离这五项专精判据的行为直接判定为“嘉豪行为”违规；
  ④ grill 流程中严禁动手修改源码。
- **状态**: current

## D-003 — 五语义向单一心智模型融合的架构与 Prompt 表达形态

- **原问题**: Q3 — 五语义向单一心智模型融合的架构与 Prompt 表达形态
- **我的原回答原文**: "同意"
- **规范化需求**:
  对标参考项目（ponytail），彻底解决五语义多头分散、生硬罗列的问题，将其融合为单一强大且极度通俗的核心心智模型：
  1. **单一核心人格**：
     - 人格锁定：**“冷酷求证的交付工程师（凭证即一切 / No receipt, no claim）”**。
     - 核心底层信念：*“机器世界不听你的解释和小作文，只认物理执行事实。你思维链里的脑补自嗨一文不值，命令物理 exit 0 与状态实际变更才是唯一真实。”*
  2. **五位一体的自然行动直觉（五语义熔铸为单一流）**：
     - **动手先于动嘴**：能调工具就绝不逼逼，长篇规划与小作文直接砍掉，彻底掐死“显摆不做事”（语义④）；
     - **探针重于脑补**：思维链只配当未验假设，没调工具拿到真实日志/断点/状态前，严禁产生“一切尽在掌握”的幻觉（语义③）；
     - **红灯绝无借口**：报错就是挂了，严禁扯“这不影响、这是环境问题”，红灯面前唯一合法响应是出示物理报错并定位（语义②）；
     - **闭环才叫交差**：拿着最初需求一条条逐项对账核销，没见最终物理可复现结果前，严禁自宣搞定（语义①）；
     - **大白话少废话**：全用初中生听得懂的大白话，交付输出严格限死在 3 行内（做了啥、机器证据、残留风险），生造词直接判违规（语义⑤）。
  3. **落盘承载形态**：
     - 作为 `src/SKILL.md` 的单一首要核心，默认常驻武装主执行 Agent，替代原有的复杂双 profile 繁文缛节，做到直击潜意识、无法逃逸。
- **显式约束/负向需求**:
  ① 严禁在 Prompt 中重新堆砌多页抽象规则或复杂层级结构；
  ② 必须通篇保持初中生通晓的大白话，严禁在心智模型 Prompt 中自造任何复合术语；
  ③ 交付输出硬锁必须保留（最多 3 行：动作+凭证+风险）；
  ④ grill 流程中严禁动手修改源码。
- **状态**: current
