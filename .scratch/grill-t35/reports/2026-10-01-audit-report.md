## 4. Process violations (reported, not ratified)

These are recorded separately from the technical findings. None of them is approved by this audit; each needs an owner call.

1. **A commit message asserts a fix that its own tree contradicts.** `8235950c` ("F-6 ritual: re-run the battery AFTER the closeout commit landed") states "pre_land green (timing satisfied…)". `check-post-land-sentinel.js` on `8235950c` fails that exact assertion. The commit's declared purpose — running the battery after the last change — is the thing that did not happen, because the block it wrote records a run from before the change it then made. Under AGENTS.md an intermediate red is disclosable; an intermediate **false green claim in a commit message** is a different class, and it is the class this round was created to eliminate.
2. **An acceptance gate marked `met` against the round's own contradictory evidence** (M-3), in a table whose adjacent row models the correct behaviour (`not claimed`). Reporting the truth in one row does not cure a false row in the same table.
3. **Owner-facing decision numbers that do not reproduce** (M-2). The report is explicit that it "states the measurement and the derivation; it does not apply them". That discipline is right, and it is also why the numbers must be correct: the owner's only input is this table.
4. **A contract relaxation carried in a code comment while the report counts two subtleties and the code counts three** (M-4). spec §2 Δ2's negative requirement and the AGENTS.md working agreement ("the ADR is the channel") both point the other way.
5. **Disclosure-surface ordering.** `8235950c` regenerated the derived surfaces and rewrote the block, but left the report's prose evidence table describing `ff4964f3`'s tree (p-1, p-2). Under E-17/E-19 the derived surfaces move last and the claims move with them; here the claims stopped moving.
6. **Scope interaction, needs an owner ruling, flagged not assumed.** `check-audit-surface.js` selects its report by `/^\d{4}-\d{2}-\d{2}-(audit|report)/` on `<round>/reports|handoffs/`, and `check-post-land-sentinel.js` selects by `CLAIM_RE` + `CLOSEOUT_RE = /(closeout|report)/`.
