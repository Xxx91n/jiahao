## Findings

### F-1 (BLOCKING) — secret-scan gate self-trips in any complete-index environment; local pass is a GitButler-index artifact

- `test/rewrite-map.test.js` lines 104/106 commit the R1 PEM-marker literal and
  an R2 provider-token-shaped literal verbatim, inside `git ls-files` scope.
- Auditor's full-tree scan (`git ls-tree -r HEAD` = 857 files through
  `scanFile`) → 2 hits, both on `test/rewrite-map.test.js`. In CI/fresh clone
  the gate exits 1 AND the jest leg `clean tree passes the gate command`
  fails. The shipped suite is self-red outside this workspace.
- Local "0 hits" is environment-artifactual: GitButler's index omits the 7
  newly committed R2 files (`git ls-files` = 850 vs `git ls-tree HEAD` = 857),
  so the scanner silently skipped its own test file. A "fail-closed" gate
  whose enumeration silently shrinks is a fail-open scope hole.

Fix requirements (for fix window): (a) make planted fixtures not match the
committed regexes — construct literals by concatenation or exclusion-list the
fixture file with a registered reason; (b) make the enumeration complete —
enumerate `git ls-tree -r HEAD` (or assert `ls-files` count == tree count and
fail-closed on mismatch), not the mutable index. (c) re-run list below.

### F-2 — A4 range-diff evidence mischaracterized

Evidence JSON and report record "15 pairs, all `!` (rewritten)"; transcript
logs "0". Reproduced: `git range-diff 1ca81f5..2c93a30 1ca81f5..051744a` =
**1 `!` pair (05fa697→2e9cdc9, the redaction diff), 13 `=` pairs, 2
left-only (112686a, 3692a86 — the emptied commits), 4 right-only (b73e558,
e54c267, a6729a9, 051744a)**. The substantive requirement (every old-side
commit maps or hits a registered disposition) is proven by `build-rewrite-map
--verify` — not by the recorded range-diff characterization. Correction of the
evidence JSON + report required; do not silently edit — register the
correction.
