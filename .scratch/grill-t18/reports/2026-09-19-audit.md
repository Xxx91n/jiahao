## 4. Findings (claim-level defects; each cites spec)

- **A-1 — defer-0060 missing from the consent-sweep named set** (D-005/D-008; task-book T-3 item 22; spec §8).
  The t18 sweep names defer-0055/0063/0053/0057/0058/sunset/O-E/patches but not
  defer-0060 (live pending-evaluation external-event row, CI 403 carrier,
  quarterly cadence). t16 and t17 sweeps both named it. The convention minted
  this round exists to prevent exactly this silent drop — its first use dropped a
  previously-named standing row without a disclosed reason. Nuance that lowers
  severity: spec §8 + ledger D-008 scoped the sweep list without defer-0060 while
  task-book item 22 included it — an internal spec inconsistency, i.e. the drop
  was pre-scoped, not an execution slip. Still undisclosed and still H-2-class.
  Adjudication needed: name defer-0060 in ledger T-3 + report sweep, or disclose
  in the ledger the reason it left the standing sweep set.

- **A-2 — export-misreport by-design documentation absent** (spec §3; D-003 R2).
  Required: "export-misreport documented by-design in round report". The report
  carries zero export/misreport text. The requirement is unfulfilled; the diff
  also added a further test-only-consumed export (SCHEMA_KEYS/PROSE_KEYS surface),
  making the missing by-design note more material, not less.

- **A-3 — committed evidence carries the H-1 corruption class; battery not fully verbatim** (D-006; item 21).
  evidence/check-ci-jobs-missing.txt records the command as
  `node scripts/check-ci-jobs.js D:` + literal 0x0A + `onexistent.yml` and the
  ENOENT path likewise contains the newline — the intended `D:\nonexistent.yml`
  (or parameterized .scratch/grill-t18/evidence/no-such-ci.yml, the t17 form) was
  eaten by an escape-interpreting layer at invocation. The exit-2 verifier-broken
  claim still verifies (ENOENT either way; this audit re-ran it with a clean arg),
  but (a) the run was not the verbatim parameterized command, and (b) the doc-
  hygiene pin covers only committed .scratch/*.md — the same-class signature in a
  committed .txt shipped undetected. Candidate: extend pin scope or register the
  .txt signature class in the defer-registry per the pin's own extensibility clause.

- **A-4 — trend-anchor streak semantics drifted under the new enum** (D-004 "streak unchanged"; ADR-0064 D-F "K=2 consecutive doc rounds").
  net_additions streak was left code-unchanged: fix rows now feed and reset the
  doc-round streak (t18 row contributes the current "streak 1 of 2"; a fix row
  with net_additions=0 would zero it). carveStreak was kind-scoped to
  documentation rows but RESETS on fix rows, so a fix round between two carve-out
  doc rounds suppresses the D-B(3) advisory — a built-in dodge. "Computation
  unchanged" is code-literal; the measured quantity changed with the enum.
  Adjudication needed: likely skip-not-reset on fix rows for both streaks.

- **A-5 — report overclaim: "Intermediate commits green throughout"** (D-008; working agreement red-mid-round rule).
  ruy (c5d3924) committed round-facts.json passed=1243 and README "1243 tests"
  while its own wiring pins raised the tree to 1244 — round-facts --check was red
  on that commit tree. The re-sync was properly disclosed on the wrx commit line
  (Amend-Riding honored — no silent amend), but the report claims the opposite of
  what the commit chain documents, and its commit-chain paragraph omits wrx/wsl.
  Reporting-accuracy defect; the underlying disclosure machinery worked.

- **A-6 — no crash wrapper on build-round-facts.js (judgment)** (D-A/D-A.1 "a crash must never masquerade as unsatisfied").
  No try/catch around main(): JSON.parse of a corrupt facts artifact or a
  spliceRegion throw exits 1 = verifier-broken masquerading as unsatisfied;
  check-ci-jobs.js carries the catch->exit 2 wrapper this convention prescribes.
  Undisclosed residual inside the convention's first-application file.

- **A-7 — checker hole: kind:fix with empty gtd.files passes** (ADR-0078 D-A MUST).
  The negative covers only governance_tooling_diff===undefined; {files:[]} passes
  shape + classification vacuously, contradicting kind:fix's own defining fact. The
  mechanism_output_diff sibling hard-fails a bare marker; no mirror here.

- **A-8 — missing-factsFile immediate exit(1) mid-phase (judgment)** (ADR-0077 D-A.1).
  Line ~201 exits 1 inside the report phase before that phase's boundary; under the
  new contract an immediate mid-phase exit is reserved for verifier-broken
  (exit>1). Defensible as an entry guard / fail-closed honesty (missing canon =
  unsatisfied, not broken), but the convention's own letter is ambiguous — worth an
  ADR clarification or a class comment.
