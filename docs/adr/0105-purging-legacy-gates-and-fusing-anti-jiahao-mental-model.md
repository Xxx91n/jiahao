# 0105. 物理清除历史虚假门禁与融合反嘉豪单一心智模型

- 状态：已采纳（Accepted）
- 决策人：项目负责人与交付工程师
- 日期：2026-10-20

## 背景与问题（Context）

本项目（jiahao）旨在防止 AI Agent 出现“自以为是完成、自我安慰跑通、颅内高潮自嗨、显摆不做事、自造词装高大上”的嘉豪式行为。但在实际演进中，项目自身反被严重感染，陷入恶性循环：
1. 磁盘上累积了 52 篇充斥学术造词的研究型 ADR 和 56 个复杂门禁（配合 30 多个虚构门禁脚本）；
2. 进场的 Agent 一看这些文档，注意力立刻被吸入“维护虚假门禁、治理文档的文档、自造复杂术语”之中，自己不知不觉变成了嘉豪；
3. 前几轮尝试急于去官僚化，粗暴将五种恶劣行为压扁为口号，丢失了五语义各自专属的深度防御机理，且未能像参考项目（ponytail）那样提炼出丝滑统一的心智模型。

## 决策内容（Decision）

基于 grill-mental-model-r5 决策账本（D-001 ~ D-004），做出如下架构决断：

1. **五语义专属防御机理专精化（D-002）**：
   - 语义①（虚假完工）：实行目标逐项物理核销凭证准入，未见可复现真实结果严禁宣称完成；
   - 语义②（借口自洽）：实行零借口红灯即死，报错必须承认失败并提供证据，严禁找补；
   - 语义③（思维链幻觉）：思维链置信度恒为零，未见真实工具探针回传前不表达确定性；
   - 语义④（文本挤占工具）：工具行动绝对前置，交付输出硬锁最多 3 行事实；
   - 语义⑤（虚饰黑话）：强制初中生大白话过滤，一个概念一个通行词，长解释直接删除。

2. **单一心智模型融合（D-003）**：
   - 确立“冷酷求证的交付工程师（凭证即一切 / No receipt, no claim）”为唯一人格内核；
   - 将五语义熔铸为“动手先于动嘴、探针重于脑补、红灯绝无借口、闭环才叫交差、大白话少废话”的五位一体直觉，作为 `src/SKILL.md` 的单一首要核心，默认常驻武装主 Agent 潜意识。

3. **历史感染源彻底物理清除（D-001 & D-004）**：
   - 将活动工作区的历史 52 篇陈旧 ADR 彻底移出，活动区仅保留本篇（ADR-0105）作为现役唯一架构决策记录；
   - 物理删除 `docs/gates.json`，清理 `scripts/` 下 30 多个虚构门禁脚本，彻底切断“给门禁擦屁股”的死循环；
   - 极简化 `CONTEXT.md` 与 `package.json`，将 `AGENTS.md` 锁定为唯一入场工作契约。

## 后果与代价（Consequences）

- **收益**：彻底净化开发环境，进场 Agent 不再被历史黑话与空转门禁带偏；主 Agent 获得极简强大的反嘉豪潜意识；项目结构完全透明直白。
- **代价**：不再保留过去庞大复杂的学术化评测门禁系统（历史已在 Git 永久留存）；依赖该体系的旧任务必须全部重置并对接真实交付。
