# 0106. 五级物理行动阶梯落地与 README 彻底脱水

- 状态：已采纳（Accepted）
- 决策人：项目负责人与交付工程师
- 日期：2026-10-20

## 背景与问题（Context）

在 ADR-0105 清除历史虚假门禁后，深入代码与工业界实证调研（arXiv 2609.19635, IFScale 等）发现两个严重妨碍交付的结构性问题：
1. **Prompt 条文化的失效**：当前 `src/SKILL.md` 将五语义写成并列的 5 条表面规则（R1~R5），实证显示散列禁令与态度性说教遵从率不足 1%，且容易被大模型静默遗漏；而参考项目 ponytail 通过单一阶梯反射（The Ladder）实现了极高遵从；
2. **README 严重自嗨污染**：现存 README 长达 22KB（中文 18KB），充斥已删除的死文件引用（score.js）、已作废的免责声明（devin-corpus@v2 评测失败）与学术黑话，成为进场 Agent 认知感染的核心源头。

## 决策内容（Decision）

基于 grill-mental-model-r6 决策账本（D-001 ~ D-003），做出如下决断：

1. **反自嗨五级物理二元行动阶梯（D-001, D-003）**：
   - 彻底摒弃散列的条款清单，将五语义专精重塑为每次交互顺次爬过的 5 级二元行动阶梯（The Action Ladder）：
     - 第 1 阶（动作前置）：有操作空间必须先调物理工具，无调用前输出文字超过 2 行直接判 FAIL；
     - 第 2 阶（探针锚定）：结论必须逐字引用真实工具探针物理回传（日志/断点/状态），无外部证据直接判 FAIL；
     - 第 3 阶（红灯即停）：exit≠0 或单测报错，唯一动作是出示证据认输停手，任何狡辩找补直接判 FAIL；
     - 第 4 阶（目标核销）：对照原始目标逐项物理对账，每项必须有当轮新跑的 exit 0 物理证据，缺一不可声称完成；
     - 第 5 阶（三行硬锁）：交付输出严格硬锁在 3 行大白话（结论+凭证+风险），包含自造复合黑话直接判 FAIL。
   - 每一级均为输出物理形态的二元判定（PASS/FAIL），最低未通过级直接阻断并驱动下一步动作；
   - 底层保持 `test/five-semantics-criteria.test.js` 物理单测与 hook 强拦截不变。

2. **README 彻底脱水与极简门面重构（D-001, D-002）**：
   - 将中英文 README 从 40KB 彻底脱水至 ~1.5KB，剔除所有历史免责声明与死引用；
   - 采用标准极简四段大白话结构（这是什么 / 行动直觉 / 宿主接入 / 物理验证）。

3. **版本库净化与远端覆盖（D-002, D-003）**：
   - 在 `.gitignore` 中加入 `.scratch`，从 Git 索引中解绑已跟踪的历史草稿与日志；
   - 本地全部物理回归 exit 0 验收后，将本地极简纯净分支强制推送覆盖至远端 GitHub 仓库（origin/main），彻底抹平远端历史污染。

## 后果与代价（Consequences）

- **收益**：彻底打通从 Prompt 行动阶梯到底层物理测试的闭环；彻底消除首页门面感染；仓库全局极度纯净。
- **代价**：需强制推送覆盖远端 Git 记录（经负责人明确授权）；需重新同步 52 个宿主适配器。
