# Domain Docs

Single-context repo. Vocabulary lives in `GLOSSARY.md` at the root.

## Before exploring, read these

1. `GLOSSARY.md` — the vocabulary every other doc uses.
2. `src/SKILL.md` — the behavior contract.

## File structure

```
/
├── GLOSSARY.md
└── src/
```

## Use the glossary's vocabulary

When writing code, docs, or issues, use the terms defined in `GLOSSARY.md`. If a
term is ambiguous or missing, resolve it and update `GLOSSARY.md` inline.

## Flag conflicts

If something contradicts the glossary, surface it explicitly instead of silently
overriding it.
